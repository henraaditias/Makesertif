# Makesertif

Generator sertifikat massal. **Semua diproses di browser** - tanpa backend, tanpa login.

## Stack & perintah

- Next.js 16 (App Router) + React 19 + Tailwind CSS 4 + TypeScript
- `npm run dev` - development server
- `npm run build` - build produksi
- `npm run lint` - ESLint

## Keputusan produk (jangan diubah tanpa diskusi)

- **Template: dua sisi** - slot **Depan (wajib)** + **Belakang (opsional)**; keduanya bisa punya field dinamis dari **kolom data yang sama** (CSV/Sheets). Field punya `side: "front" | "back"`; canvas & preview step 4 punya tab Depan/Belakang; PDF gabungan = per baris halaman depan lalu halaman belakang (bila ada). **Step template menampilkan satu preview sisi aktif** (bukan dua slot berdampingan): klik preview = ganti gambar sisi itu; toggle pill `Depan`/`Belakang` di bawah preview **dengan posisi & gaya sama seperti toggle File CSV/Sheets** (`Belakang` disabled sampai template belakang ada; setelah upload belakang otomatis berpindah ke sisi belakang); action bar kiri = `Tambahkan tampilan belakang` / `Hapus tampilan belakang` (konfirmasi lewat **`ConfirmModal`** bila ada field di sisi itu) - **tidak ada tombol `Ubah File` di step ini**.
- **Output unduhan: 3 opsi, panel inline (tanpa menu popup)** - pilihan **format** & **kualitas** ada di panel `Unduh` di konten step 4: **tata letak tiga kolom `flex flex-wrap` (Format file · Kualitas · Nama file) yang menumpuk sendiri di layar sempit** - kesepakatan user: jangan semuanya berjajar ke bawah; estimasi/progres tetap baris lebar penuh di bawah ketiga kolom. Format & kualitas memakai segmented control `Segmented` (indikator pill meluncur via anime.js); nama file = dropdown select kolom. Tombol primary `Unduh`/`Unduh PDF satuan`/`Unduh PNG` di action bar **langsung menjalankan format terpilih**. Menu popup lama di atas tombol sudah dihapus (backdrop & `DOWNLOAD_OPTIONS` di wizard tidak ada). Tiga format:
  1. **PDF gabungan** multi-halaman (A4 landscape, jsPDF + rendering `<canvas>`).
  2. **PDF satuan** - 1 file PDF per sertifikat (depan+belakang) → **ZIP** (`pdf-satuan.zip`) - bila cuma 1 file, unduh langsung tanpa ZIP.
  3. **Gambar PNG** - render per baris per sisi → **ZIP** (`gambar-satuan.zip`); suffix `-depan`/`-belakang` hanya bila template belakang ada.
  **Kualitas render** (untuk ketiga format, preset di `app/lib/quality.ts`, disimpan di draft): `Normal` = A4 200 DPI (2339×1654), **`HD` = default**, A4 400 DPI (4677×3307, sama dengan render lama), `4K` = lebar 3840 px (3840×2715). `pdf.ts` menerima `quality` + `onProgress(done,total)`; batas tajam tetap resolusi template. **Estimasi waktu**: panel menampilkan `Perkiraan ± X detik - N halaman · kualitas …` (heuristik ms/baris per level + faktor format, lalu ditimpa **hasil ukur nyata** yang disimpan di key `gc:perf` - `recordMsPerRow`), saat berjalan berubah jadi **progress bar + hitung mundur** (`42 / 200 halaman · sisa ± 28 detik`) yang dihitung dari rata-rata baris selesai (tick 500 ms, `performance.now` dipanggil di effect, bukan render). Loop generate memberi giliran browser tiap baris (rAF / `setTimeout(0)`) supaya progres sempat dirender.
  ZIP ditulis sendiri di `app/lib/zip.ts` (store-only + CRC32 + flag UTF-8) - **tanpa dependency baru**; sudah diverifikasi test roundtrip + ekstraksi .NET.
  **Nama file** (opsi 2 & 3) = `2026-001_Budi`: tahun berjalan - **nomor urut 3 digit per paket unduhan** (`001`, `002`, … urut baris terpilih) - **nilai kolom pilihan user** (dropdown di step 4, default kolom pertama) - `buildFileName(column, row, index)` di `app/lib/filename.ts` + sanitasi karakter Windows; pilihan kolom disimpan di draft sebagai `fileNameColumn` (input pola `{Kolom}` lama sudah dihapus; key lama `filePattern` diabaikan).
- **Sumber data: `File CSV` dan `Google Sheets`** (toggle di step Entering data, tampil sebelum data terupload - setelah upload toggle tidak tampil lagi). **Tombol `Ubah File` kini ada di ACTION BAR** (slot kiri, sejajar `Sebelumnya` · `Lanjutkan`, sebelah kanan tombol `Sebelumnya` - keputusan user: di dalam konten tombol ikut tergulir hilang saat data panjang; muncul hanya di step Masukkan Data + `rows.length > 0`) - diklik = kembali ke tampilan awal sebelum input (CSV → zone kosong, Sheets → input link + fokus; seleksi baris di-reset) - satu-satunya aksi ganti di layar itu, tanpa link tambahan lain. Link Google Sheets publik dikonversi ke endpoint `gviz/tq?tqx=out:csv` lalu di-fetch client-side. **CORS sudah diverifikasi via curl**: gviz membalas 200 `text/csv` dan me-reflect `Access-Control-Allow-Origin` sesuai Origin; respons privat/tidak valid TIDAK punya ACAO sehingga fetch gagal sebagai `TypeError` - tangkap dan sarankan fallback File CSV. **Validasi file CSV** (di `handleCsvFile`): ekstensi wajib `.csv` (drag-drop lolos dari `accept`) lalu isi dicek `looksBinary()` (`app/lib/csv.ts` - byte NUL / karakter kontrol >2% / replacement char, cek 4 KB pertama) → pesan jelas "File bukan CSV…" / "Isi file bukan teks CSV…" alih-alih teks berantakan seperti ter-encrypt (khas .xlsx yang diganti nama). **Preview tabel memakai virtual scrolling** (di `DataTable`, tanpa library): >100 baris → hanya baris di viewport ± 10 overscan yang dirender, sisanya spacer `<td>` setinggi selisihnya; tinggi baris diukur dari baris nyata (rAF) + `ResizeObserver` viewport, scroll di-rAF-throttle, header `sticky top-0`; zebra pakai index genap/ganjil (bukan `even:` - urutan DOM sudah tidak penuh).
- **Elemen canvas: teks dinamis (field) saja** - kolom dari data, digeser dengan drag & drop, posisi disimpan sebagai % relatif, per sisi template (`side`). Tanpa gambar/QR/tanda tangan. Font Color: 4 swatch cepat (Ink/Putih/Merah/Biru) + color picker native + input HEX (juga terima `rgb(...)`) dengan readout RGB; **tombol picker dibentuk kotak berbingkai + ikon palet** agar tidak disamakan dengan swatch bulat. **Teks field tidak boleh keluar tepi canvas**: kotak field `width = field.width ?? (100-x)%` + `white-space: pre-wrap; word-break: break-word` → teks membungkus ke bawah dalam batas template; renderer PDF/PNG memakai wrap greedy yang sama (`wrapLines` di `app/lib/text-wrap.ts`). **Ukuran kotak bisa diubah user lewat SATU handle bulat di kanan-bawah** (keputusan user: versi 4 titik sempat error → kembali satu handle, tapi kini DUA dimensi) - geser horizontal = ubah `FieldConfig.width` (%), `x` diam; geser vertikal = ubah `FieldConfig.height` (%) - properti **opsional** baru (tanpa itu tinggi kotak otomatis mengikuti teks, draft lama aman); cursor `nwse-resize`, lebar minimum 5%, tinggi minimum 2%, dijaga `x + width ≤ 100` & `y + height ≤ 100` - **tinggi hanya membatasi kotak (outline)**: teks tetap digambar dari atas kotak di DOM, preview step 4, dan renderer PDF/PNG (tanpa perubahan di `pdf.ts`). **Gaya field ala Canva (bukan ring kotak keras)**: hover → `outline-dashed` (**offset 0 - menempel di tepi kotak; keputusan user: efek hover tidak boleh terpotong tepi foto/area scroll**) + `cursor-grab`, terpilih → `outline-solid outline-accent` + **satu handle bulat kanan-bawah** (`size-4`, hover scale), saat digeser/di-resize → **lift `shadow-lift`** (token baru di `globals.css`) + `cursor-grabbing`; transisi 150 ms hanya `box-shadow/outline-color/width/font-size` (**dimatikan selama drag** supaya posisi tetap instant - `left/top` memang tidak pernah ditransisikan) + `motion-reduce:transition-none`; `onTransitionEnd` (font-size/width) memicu render ulang agar clamp mengukur tinggi kotak FINAL setelah transisi (memperbaiki celah satu-langkah di mana field bisa sempat keluar tepi bawah). **Gaya teks dua toggle terpisah**: select `Jenis font` hanya memilih keluarga (`FONT_FAMILIES` = Inter / Times New Roman / Georgia), lalu `fontWeight` (400/700) & `fontStyle?: "normal"|"italic"` di-toggle lewat tombol `B`/`I` → 1 keluarga bisa reguler, tebal, miring, atau keduanya (Inter italic dimuat `next/font` dengan `style: ["normal","italic"]`; spec per gaya = `fontSpec()`). **Perataan**: `align?: "left"|"center"|"right"` (default kiri) lewat tombol ikon - dipakai identik di DOM canvas, preview step 4, dan `ctx.textAlign` di renderer PDF/PNG (titik gambar dihitung dari tepi kotak). **Field TIDAK BISA keluar foto** - dijaga satu tempat: `useEffect` clamp di `edit-canvas` menutup `x + width ≤ 100` (lebar default `100−x` dijaga ≥ 5%) dan `y + tinggi kotak ≤ 100` **setelah semua patch**, termasuk saat ukuran font/kolom berubah (tinggi kotak ikut berubah). **Daftar field + tombol `Tambah field` di panel kanvas scroll sendiri** (`max-h-72 overflow-y-auto` + `p-1` bantalan supaya ring/hover baris tidak terpotong tepi area scroll - keputusan user: >±4 baris tidak menjulang memaksa seluruh isi halaman menggulir) dan **UI scroll pakai anime.js** (keputusan user): scrollbar native disembunyikan (`.no-scrollbar` di `globals.css`) lalu diganti **thumb custom** `bg-primary/40` di track kanan panel - tinggi/posisi ditulis langsung DOM dari metrik scroll + `ResizeObserver` (tanpa re-render), muncul fade-in lalu hilang fade-out setelah idle 0,9 dtk saat scroll/hover (`animateSafe`), tanpa thumb bila daftar tidak meluap; klik `Tambah field` → **gulir halus anime.js ke baris baru** (`animateScrollElTo`). Semua properti baru opsional → draft lama tetap terbaca tanpa migrasi.

Entri metode selain store / ZIP64 dilewati; diverifikasi test roundtrip Node (termasuk nama UTF-8).
