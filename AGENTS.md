# GenerateCertificate

Generator sertifikat massal. **Semua diproses di browser** — tanpa backend, tanpa login.

## Stack & perintah

- Next.js 16 (App Router) + React 19 + Tailwind CSS 4 + TypeScript
- `npm run dev` — development server
- `npm run build` — build produksi
- `npm run lint` — ESLint

## Keputusan produk (jangan diubah tanpa diskusi)

- **Template: dua sisi** — slot **Depan (wajib)** + **Belakang (opsional)**; keduanya bisa punya field dinamis dari **kolom data yang sama** (CSV/Sheets). Field punya `side: "front" | "back"`; canvas & preview step 4 punya tab Depan/Belakang; PDF gabungan = per baris halaman depan lalu halaman belakang (bila ada). **Step template menampilkan satu preview sisi aktif** (bukan dua slot berdampingan): klik preview = ganti gambar sisi itu; toggle pill `Depan`/`Belakang` di bawah preview **dengan posisi & gaya sama seperti toggle File CSV/Sheets** (`Belakang` disabled sampai template belakang ada; setelah upload belakang otomatis berpindah ke sisi belakang); action bar kiri = `Tambahkan tampilan belakang` / `Hapus tampilan belakang` (konfirmasi bila ada field di sisi itu) — **tidak ada tombol `Ubah File` di step ini**.
- **Output unduhan: 3 opsi, panel inline (tanpa menu popup)** — pilihan **format** & **kualitas** ada di panel `Unduh` di konten step 4: **tata letak tiga kolom `flex flex-wrap` (Format file · Kualitas · Nama file) yang menumpuk sendiri di layar sempit** — kesepakatan user: jangan semuanya berjajar ke bawah; estimasi/progres tetap baris lebar penuh di bawah ketiga kolom. Format & kualitas memakai segmented control `Segmented` (indikator pill meluncur via anime.js); nama file = dropdown select kolom. Tombol primary `Unduh`/`Unduh PDF satuan`/`Unduh PNG` di action bar **langsung menjalankan format terpilih**. Menu popup lama di atas tombol sudah dihapus (backdrop & `DOWNLOAD_OPTIONS` di wizard tidak ada). Tiga format:
  1. **PDF gabungan** multi-halaman (A4 landscape, jsPDF + rendering `<canvas>`).
  2. **PDF satuan** — 1 file PDF per sertifikat (depan+belakang) → **ZIP** (`pdf-satuan.zip`) — bila cuma 1 file, unduh langsung tanpa ZIP.
  3. **Gambar PNG** — render per baris per sisi → **ZIP** (`gambar-satuan.zip`); suffix `-depan`/`-belakang` hanya bila template belakang ada.
  **Kualitas render** (untuk ketiga format, preset di `app/lib/quality.ts`, disimpan di draft): `Normal` = A4 200 DPI (2339×1654), **`HD` = default**, A4 400 DPI (4677×3307, sama dengan render lama), `4K` = lebar 3840 px (3840×2715). `pdf.ts` menerima `quality` + `onProgress(done,total)`; batas tajam tetap resolusi template. **Estimasi waktu**: panel menampilkan `Perkiraan ± X detik — N halaman · kualitas …` (heuristik ms/baris per level + faktor format, lalu ditimpa **hasil ukur nyata** yang disimpan di key `gc:perf` — `recordMsPerRow`), saat berjalan berubah jadi **progress bar + hitung mundur** (`42 / 200 halaman · sisa ± 28 detik`) yang dihitung dari rata-rata baris selesai (tick 500 ms, `performance.now` dipanggil di effect, bukan render). Loop generate memberi giliran browser tiap baris (rAF / `setTimeout(0)`) supaya progres sempat dirender.
  ZIP ditulis sendiri di `app/lib/zip.ts` (store-only + CRC32 + flag UTF-8) — **tanpa dependency baru**; sudah diverifikasi test roundtrip + ekstraksi .NET.
  **Nama file** (opsi 2 & 3) = `2026-001_Budi`: tahun berjalan - **nomor urut 3 digit per paket unduhan** (`001`, `002`, … urut baris terpilih) - **nilai kolom pilihan user** (dropdown di step 4, default kolom pertama) — `buildFileName(column, row, index)` di `app/lib/filename.ts` + sanitasi karakter Windows; pilihan kolom disimpan di draft sebagai `fileNameColumn` (input pola `{Kolom}` lama sudah dihapus; key lama `filePattern` diabaikan).
- **Sumber data: `File CSV` dan `Google Sheets`** (toggle di step Entering data, tampil sebelum data terupload). **Setelah terupload, toggle diganti tombol `Ubah File` di posisi yang sama** — diklik = kembali ke tampilan awal sebelum input (CSV → zone kosong, Sheets → input link + fokus; seleksi baris di-reset) — satu-satunya aksi ganti di layar itu, tanpa link tambahan lain. Link Google Sheets publik dikonversi ke endpoint `gviz/tq?tqx=out:csv` lalu di-fetch client-side. **CORS sudah diverifikasi via curl**: gviz membalas 200 `text/csv` dan me-reflect `Access-Control-Allow-Origin` sesuai Origin; respons privat/tidak valid TIDAK punya ACAO sehingga fetch gagal sebagai `TypeError` — tangkap dan sarankan fallback File CSV.
- **Elemen canvas: teks dinamis (field) saja** — kolom dari data, digeser dengan drag & drop, posisi disimpan sebagai % relatif, per sisi template (`side`). Tanpa gambar/QR/tanda tangan. Font Color: 4 swatch cepat (Ink/Putih/Merah/Biru) + color picker native + input HEX (juga terima `rgb(...)`) dengan readout RGB; **tombol picker dibentuk kotak berbingkai + ikon palet** agar tidak disamakan dengan swatch bulat. **Teks field tidak boleh keluar tepi canvas**: kotak field `width = field.width ?? (100-x)%` + `white-space: pre-wrap; word-break: break-word` → teks membungkus ke bawah dalam batas template; renderer PDF/PNG memakai wrap greedy yang sama (`wrapLines` di `app/lib/text-wrap.ts`). **Lebar bisa diubah user** lewat handle kanan-bawah kotak field terpilih (cursor `nwse-resize`) → menyimpan `FieldConfig.width` (%). **Gaya teks dua toggle terpisah**: select `Jenis font` hanya memilih keluarga (`FONT_FAMILIES` = Inter / Times New Roman / Georgia), lalu `fontWeight` (400/700) & `fontStyle?: "normal"|"italic"` di-toggle lewat tombol `B`/`I` → 1 keluarga bisa reguler, tebal, miring, atau keduanya (Inter italic dimuat `next/font` dengan `style: ["normal","italic"]`; spec per gaya = `fontSpec()`). **Perataan**: `align?: "left"|"center"|"right"` (default kiri) lewat tombol ikon — dipakai identik di DOM canvas, preview step 4, dan `ctx.textAlign` di renderer PDF/PNG (titik gambar dihitung dari tepi kotak). **Field TIDAK BISA keluar foto** — dijaga satu tempat: `useEffect` clamp di `edit-canvas` menutup `x + width ≤ 100` (lebar default `100−x` dijaga ≥ 5%) dan `y + tinggi kotak ≤ 100` **setelah semua patch**, termasuk saat ukuran font/kolom berubah (tinggi kotak ikut berubah). Semua properti baru opsional → draft lama tetap terbaca tanpa migrasi.
- **Penyimpanan: localStorage** dengan key:
  - `gc:draft` — sesi kerja (step aktif, link data, konfigurasi field **termasuk sisi & lebar per field**, **kedua template sebagai data URL**, kolom penamaan file, **format & kualitas unduhan**), dipulihkan otomatis saat refresh — debounce 300 ms + flush `pagehide`; file besar dire-encode; `QuotaExceededError` → buang salinan PDF dulu, lalu template belakang, baru template depan (draft lama tanpa field baru tetap terbaca — semua field baru bersifat opsional)
  - `gc:perf` — hasil ukur kecepatan generate (ms/baris per kombinasi kualitas+format) untuk estimasi waktu; **bukan bagian draft**, ikut dibersihkan `Hapus Data` (kini 4 key `GC_KEYS`)
  - `gc:history` / `gc:pdfs` — **fitur History sudah dihapus total** (panel History di step 4, penulisan log & salinan PDF, `pushHistory`/`savePdf` sudah tidak ada); key lama tetap ikut dibersihkan oleh tombol `Hapus Data` (semua key `GC_KEYS`) dan oleh fallback kuota `saveDraft` yang membuang `gc:pdfs` dulu
  - **Refresh TIDAK menghapus data** — satu-satunya cara menghapus adalah tombol `Hapus Data` di navbar (konfirmasi → hapus semua key localStorage `GC_KEYS` → reload); tombol ini **hanya menghapus data tampilan sertifikat — data Dashboard (IndexedDB) tidak tersentuh**.
- **Dashboard `/dashboard` — riwayat file di IndexedDB (bukan localStorage)**: db `gc-files` dengan store metadata (`templates`/`datasets`/`results`) + `files` (blob) menyimpan file template, file CSV, link Sheets, dan hasil unduhan (PDF/ZIP) → semua bisa **diunduh ulang** dari dashboard. **Masa simpan 24 jam**: banner TTL + countdown per item + notice saat data lama dihapus otomatis (prune jalan saat halaman dibuka, setelah tiap simpan, dan interval 60 detik selama terbuka). **TANPA batas ukuran file** (keputusan user — `MAX_FILE_BYTES`/`MAX_RESULT_BYTES` dihapus): semua file termasuk `gambar-satuan.zip` ratusan MB selalu dicoba disimpan; cap 30 entri/store; quota penuh → evict file terlama lalu coba ulang (maks 3×); **bila tetap gagal, metadata tetap disimpan tanpa file** (`persist` mengisi `hasFile: false` → entri tetap tampil di dashboard, hanya tombol `Unduh ulang` yang tidak muncul — baris hasil diberi keterangan "file tidak disimpan di browser"). **Status unduhan (loading + estimasi)**: klik `Unduh`/`Unduh ulang` (baris mana pun atau di modal Pratinjau) → strip status di atas kotak: fase **`Menyiapkan file…`** (baca IndexedDB) → **`Mengunduh`** (anchor browser), lengkap dengan ukuran file, **`sisa ± …`** (heuristik `downloadTiming()` — 80 MB/s + overhead, teks `formatDurationMs`) dan progress bar `bg-action` (transisi CSS `width`, **bukan** anime.js); tombol yang diklik jadi `loading`, tombol lain `disabled` selama proses; fase error hilang otomatis 6 dtk, status macet ditutup otomatis 15 dtk, dan bisa ditutup manual (×). `Date.now()` untuk timing dipanggil di `app/lib/download.ts`, bukan di badan komponen (aturan `react-hooks/purity`). **Pratinjau semua baris** (tombol `Pratinjau` ikon mata di ketiga panel + modal): File Sertifikat → gambar ukuran penuh; Data CSV → tabel 50 baris pertama; Data Google Sheets → tabel via fetch gviz; Hasil Generate → PDF gabungan dibuka iframe browser, ZIP dibuka `lib/unzip` lalu ditampilkan isinya (navigator ‹ n/N › + daftar nama file) — semua oleh `app/dashboard/preview-modal.tsx`, tanpa animasi, tombol `Unduh` ikut di dalam modal. **Hapus terpisah**: tombol `Hapus Data` navbar di `/certificate` hanya menghapus `gc:draft` + key legacy; halaman dashboard punya `Hapus Data` sendiri (prop `onDeleteData`) yang mengosongkan store IndexedDB. Wizard memanggil `save*Record` saat upload/generate secara fire-and-forget — **gagal simpan riwayat tidak boleh mengganggu unduhan**. Prinsip sama dengan keputusan sebelumnya: file TIDAK pernah masuk localStorage (kuota 5MB). **Tampilan (mengikuti mockup)**: kartu `h-dvh` seperti wizard — halaman TIDAK scroll; urutan atas ke bawah = navbar → baris judul `Dashboard` + primary `Buat Sertifikat` (tanpa subteks deskripsi) → **banner `bg-danger` teks putih + ikon** (masa simpan 24 jam) → notice prune/error → **kotak isi** → footer (paling bawah, di luar scroll). **Kotak = akordeon 3 panel horizontal** (File Sertifikat · Data · Hasil Generate — default yang melebar = **Hasil Generate**/kanan): panel aktif melebar berisi header (ikon + judul + `N data`) + daftar yang **satu-satunya area scroll** (`min-h-0 overflow-y-auto`); panel non-aktif jadi tab sempit (48px, 56px di ≥1024px) berisi ikon, judul diputar (`writingMode: vertical-rl`), dan angka jumlah — diklik → melebar & yang tadinya melebar menyempit; klik panel aktif tidak membuat semua-menutup. **Lebar panel diatur imperative (inline `width` px) dari `dashboard.tsx`, bukan class Tailwind** — React tidak boleh menulis `width` panel agar tidak melawan animasi; `useAnimationLayoutEffect` memasang lebar sebelum paint pertama, `resize` reposisi tanpa animasi. **Gambar template**: thumbnail DIKECILKAN dulu ke JPEG 256px via `createImageBitmap` (decode off main thread) lalu di-cache per id + dipanaskan `warmThumbs` setelah paint pertama → buka panel tidak nge-frame (placeholder ikon tampil selama dimuat); tiap baris File Sertifikat (bila `hasFile`) punya tombol **`Pratinjau`** (modal gambar ukuran penuh — tutup via Esc / `Tutup` / klik latar, tanpa animasi) dan **`Unduh`** (blob asli, kualitas penuh).
- **Halaman utama `/` dan `/privacy` masih placeholder kosong** — konten lengkap (landing mengikuti mockup `rev/`, teks kebijakan privasi) ditunda; keduanya hanya berisi navbar + pesan singkat + footer. **Animasi terbatas pada fade-up sekali via `FadeIn` (anime.js)** yang sudah disetujui diskusi — jangan menambah animasi lain atau dependency baru tanpa diskusi lagi.
- **Animasi: anime.js v4 (`animejs@^4.5.0`, dependency baru — disetujui eksplisit)**: pembungkus `app/lib/animations.ts` (`prefersReducedMotion`, `animateSafe`, `fadeInUp`, `useAnimationLayoutEffect`) + komponen `FadeIn` & `Segmented` (`app/components/common/`). **Semua animasi dilewati bila `prefers-reduced-motion`** (elemen langsung tampil normal), cleanup selalu dipasang di `useEffect`, warna/ukuran tetap token Tailwind (anime hanya menggerakkan opacity/transform/`left`/`width`). Cakupan saat ini: **loading generate** (deret titik `stagger` loop + progress bar `bg-action`), **pop banner sukses** (`outBack`), **crossfade preview** Depan/Belakang, **transisi antar step** (fade-up), **indikator segmented meluncur**, **lebar panel akordeon dashboard** (`width` panel melebar/mengecil — 320 ms `outCubic`, dipasang via `useAnimationLayoutEffect`), dan fade-up masuk halaman `/` + `/privacy`.
- **Bahasa antarmuka: Indonesia** — semua teks yang dilihat pengguna (landing, halaman privacy, step nav, label tombol, pesan error) ditulis bahasa Indonesia. Istilah baku dibiarkan dalam Inggris: `File CSV`, `Google Sheets`, `PDF`, `PNG`, `ZIP`, `Privacy policy`, nama font, dan style font `Normal`/`Bold`. Design.md sudah disesuaikan dengan teks ini.
- **UI light-only**, font Inter, tanpa varian dark mode.
- **Layout wizard: hanya isi step yang scroll** — kartu setinggi viewport (`h-dvh`); step nav (kiri) statis, kolom kanan dipecah jadi area konten (`min-h-0 overflow-y-auto`) + **action bar di luar area scroll** sehingga `Lanjutkan`/`Unduh` selalu terlihat, footer privasi menempel di bawah. Berlaku untuk semua step. **Toggle `Depan`/`Belakang` ada di BAWAH canvas (step 3) dan BAWAH preview (step 4)** — sejajar dengan posisinya di step Template. **Ikon bantuan `?` di pojok kanan atas kartu wizard sudah DISIAPKAN (permintaan user: hilangkan dulu, nanti dipasang lagi)** — tombolnya sudah dihapus dari `certificate-wizard.tsx`; struktur `relative` di `section` tetap dipertahankan agar mudah dipasang kembali.
- **Responsif**: layar **<768px di wizard & dashboard (`/dashboard`) diblokir overlay selayar** (`RotateGate` — dua paragraf bahasa Indonesia, "putar perangkat ini atau gunakan laptop") — dirotot ke landscape (≥768px) web langsung tampil; ≥768px menyesuaikan: sidebar step ~210px + padding rapat di tablet portrait (768–1023px), panel properti canvas ditumpuk di bawah canvas, ≥1024px seperti desktop. **HP dirotot (tinggi ≤500px) didukung penuh lewat varian `short`** (`@custom-variant` di `globals.css`, `@media (max-height: 500px)`): padding & tinggi minimum wizard dikompakkan, panel properti canvas pindah ke samping + scroll internal, tinggi gambar canvas/preview dibatasi `dvh`, dan drag/resize field di kanvas memakai pointer events + `touch-none` sehingga berfungsi dengan sentuhan. **Halaman utama (`/`) dan `/privacy` TIDAK diblokir overlay** — tetap terbaca di layar kecil; wizard memakai `h-dvh` (kartu = viewport, scroll di dalam kolom konten), halaman lain memakai `min-h-dvh` (viewport dinamis URL-bar mobile).

## Struktur

- `app/page.tsx` — halaman utama (`/`), render `Landing` — **masih placeholder kosong**.
- `app/components/home/landing.tsx` — halaman utama: placeholder kosong (navbar + pesan singkat + link ke /certificate + footer); konten menyusul.
- `app/privacy/page.tsx` — halaman Privacy policy (dari link footer) — **masih placeholder kosong**; teks kebijakan menyusul.
- `app/certificate/page.tsx` — halaman wizard utama (**fokus utama proyek**), render `CertificateWizard`.
- `app/dashboard/page.tsx` — halaman Dashboard (server, metadata) yang render `dashboard.tsx` (client): baris judul `Dashboard` + `Buat Sertifikat`, banner danger TTL 24 jam, **kotak akordeon 3 panel riwayat** (File Sertifikat / Data / Hasil Generate, hanya panel aktif yang scroll), notice prune, unduh ulang + pratinjau semua baris, hapus sesi.
- `app/components/flow/certificate-wizard.tsx` — shell halaman: state machine 4 step, action bar, mount step components. 4 step: `Template Sertifikat` → `Masukkan Data` → `Desain di Kanvas` → `Selesaikan Proses`.
- `app/components/flow/types.ts` — tipe bersama (`DataSource`, `DataRow`, `FieldConfig` termasuk `fontStyle` & `align`, `TemplateSide`, `DownloadKind`, `QualityLevel`, `GenerateProgress`, `TextAlign`, `DOWNLOAD_BUTTON_LABEL`) + helper aman-draft-lama `fieldSide`, `fieldItalic`, `fieldAlign`.
- `app/lib/csv.ts` — parser CSV ringan (quoted field, CRLF, BOM, header duplikat).
- `app/lib/sheets.ts` — konversi link Google Sheets → endpoint gviz CSV (lihat catatan CORS).
- `app/lib/fonts.ts` — `FONT_FAMILIES` (keluarga font canvas: Inter / Times New Roman / Georgia), `fontSpec(style, weight, family)` (spec `document.fonts.load` per gaya italic/bold), swatch warna + helper warna (`hexToRgb`, `parseColorInput`) untuk panel canvas & render PDF.
- `app/lib/pdf.ts` — render PDF A4 landscape (jsPDF + canvas) untuk 3 opsi unduhan: `buildCertificatePdf` (gabungan; `rows: [row]` = satuan) dan `renderRowPngs` (PNG per sisi) — keduanya menerima `quality` (Normal/HD/4K) dan opsi `onProgress(done,total)`; `nextPaint()` memberi giliran browser tiap baris.
- `app/lib/quality.ts` — preset kualitas render (`QUALITY_PRESETS`, `qualityPixels`, `qualityPixelLabel`, `DEFAULT_QUALITY` = `hd`) + estimasi waktu (`estimateDurationMs`, `recordMsPerRow`/`measuredMsPerRow` → key `gc:perf`, `formatDurationMs`) + konstanta mm A4 (`A4_W_MM`/`A4_H_MM` dipakai `pdf.ts`).
- `app/lib/animations.ts` — pembungkus anime.js v4: `prefersReducedMotion`, `animateSafe` (main + cleanup pause), `fadeInUp` (opacity diset sebelum animasi → tanpa kedip), `useAnimationLayoutEffect` — semua dilewati bila reduced motion.
- `app/lib/filename.ts` — nama file unduhan `tahun-nomor_kolom` (`buildFileName(column, row, index)` + sanitasi Windows, `uniqueFileName` anti-bentrok di ZIP).
- `app/lib/text-wrap.ts` — pemecah baris teks (`wrapLines`) agar PDF/PNG konsisten dengan wrap DOM di canvas.
- `app/lib/zip.ts` — penulis ZIP store-only tanpa dependency (`crc32`, `createZip`).
- `app/lib/unzip.ts` — pembaca ZIP store-only (pasangan `zip.ts`) untuk pratinjau isi hasil: `listZipEntries` baca central directory di ekor file (1 pembacaan) → daftar nama/ukuran/offset; `readZipEntry` baca header lokal 30 byte lalu `slice` blob pada posisi data (bytes tak dimuat penuh ke memori); `isImageName`. Entri metode selain store / ZIP64 dilewati; diverifikasi test roundtrip Node (termasuk nama UTF-8).
- `app/lib/idb.ts` — wrapper IndexedDB `gc-files` (store metadata + `files` blob, evict terlama saat quota); **satu-satunya tempat file besar — localStorage tidak dipakai untuk file**.
- `app/lib/activity.ts` — domain dashboard: TTL 24 jam (`TTL_MS`), cap 30, `saveTemplateRecord`/`saveDatasetRecord`/`saveResultRecord` (tak pernah melempar error), `loadDashboard` (prune lalu listing + bersihkan blob yatim), `clearDashboard`, helper murni `sisaWaktuLabel`/`formatUkuran` (diuji di Node).
- `app/lib/thumb.ts` — thumbnail dashboard agar buka panel tidak nge-frame: `thumbUrl(id)` memuat blob → resize via `createImageBitmap` (off main thread) → JPEG 256px, hasilnya di-cache sebagai object URL per id (TIDAK di-revoke selama tab terbuka); `cachedThumb(id)` cek cache tanpa memuat; `warmThumbs(ids)` memanaskan cache setelah paint pertama (idle + jeda 30 ms antar gambar). **Thumbnail hanya untuk tampilan — tombol Unduh/Pratinjau selalu memakai blob ASLI lewat `loadFileBlob`.**
- `app/lib/download.ts` — timing & estimasi unduhan dashboard: `downloadTiming(size)` → `{ startedAt, totalMs }` (heuristik `DOWNLOAD_MBPS` 80 MB/s + overhead 400 ms, minimum 800 ms) untuk strip status loading; `Date.now()` dipanggil DI SINI supaya badan komponen tetap murni (`react-hooks/purity`).
- `app/dashboard/preview-modal.tsx` — **modal pratinjau universal semua baris dashboard** (`PreviewModal` + tipe `PreviewTarget`): gambar (blob asli), tabel File CSV 50 baris pertama (`parseCsv`) / Google Sheets (fetch gviz, siapkan pesan bila link tidak publik), hasil PDF gabungan (iframe browser), isi ZIP (`listZipEntries` → navigator ‹ n/N › + daftar nama, `key` per sasaran supaya state segar). Tanpa animasi; tombol `Unduh` ikut di modal. Baris tanpa file unduhan (Sheets) tidak mengirim prop `download`.
- `app/components/flow/` — komponen per step (`upload-certificate`, `upload-data`, `edit-canvas`, `result`), di-mount oleh wizard.
- `app/components/common/` — primitives (`button.tsx` berisi `Button` + `ButtonLink`, `icons.tsx` SVG inline, `rotate-gate.tsx` overlay <768px untuk wizard & dashboard, `segmented.tsx` radiogroup pill dengan indikator meluncur (anime.js), `fade-in.tsx` fade-up mount halaman luar wizard).
- `app/components/layout/` — `navbar.tsx`, `footer.tsx`.
- `rev/` — mockup PNG & sheet komponen. **Referensi visual saja, bukan source code.**
- `Design.md` — sumber kebenaran design system. Token sudah diimplementasikan di `app/globals.css`.

## Aturan coding

- Sebelum menulis kode Next.js, baca guide lokal di `node_modules/next/dist/docs/` (lihat block di atas).
- **Satu primary action per layar** (prinsip Design.md).
- Tailwind: pakai token dari `globals.css` (`bg-primary`, `text-ink`, `border-line`, `rounded-control`, `text-title`, `shadow-card`, dst.) — jangan warna/ukuran hardcoded.
- Ikon: inline SVG, tanpa menambah dependency ikon.
- Penamaan: komponen PascalCase dengan `export default`; nama file `result.tsx` (bukan `reasult.tsx`).
- Halaman bersifat client-heavy (upload, canvas, localStorage) — gunakan `"use client"` hanya di komponen yang membutuhkannya.
